Production Upgrade
=================
Local - C:/users/monty/Golf/montgolf - NO TAGS
-------------------------------------------------------------------------
	git status
	git add *
	git commit -m "description of changes"
	git push origin main

Local - C:/users/monty/Golf/montgolf - TAGS
--------------------------------------------------------------------
	git fetch --tags
	git tag -a v1.1.0 -m "description of release"
	git push origin v1.1.0

Production - NO TAGS
----------------------------------
	cd  - /var/www/montgolf/
	git pull origin main
	npm install
	pm2 restart montgolf   (or systemctl restart montgolf)

Production - TAGS
-----------------------------
	git fetch --tags
	git checkout v1.0.0
	pm2 restart montgolf
